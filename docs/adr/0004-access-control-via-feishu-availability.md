# Access control is delegated to the Feishu app's availability scope

Who can talk to tanomu and who can add it to a group is decided entirely by the "availability scope" in the Feishu developer console; the code performs no User or group checks. During personal use the scope is just the owner; rolling out means widening the scope. The admin console only requires Feishu OAuth login, so anyone in the same Feishu tenant can sign in — there is no admin role. This keeps v1 simple; the cost is that anyone who can sign in can change configuration and see Provider API keys. If the team grows or a misconfiguration happens, adding an admin allowlist back is the first fix.
